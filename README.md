Furf Addon: The Catharsis Companion
Furf Addon is an essential overlay specifically designed for the current 1.21.11 Catharsis Beta version of FurfSky-Reborn. This addon focuses on refining the user experience by resolving existing bugs and restoring beloved classic textures that were previously removed. It also introduces various minor visual improvements to ensure the pack feels both nostalgic and polished.

Important: This addon is not standalone. To function correctly, it must be loaded alongside the official FurfSky-Reborn pack. For the best results, ensure this addon is placed at the very top of your resource pack list!
